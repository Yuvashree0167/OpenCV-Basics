# OpenCV Basics

A beginner-friendly collection of image processing projects using Python, OpenCV, and imutils.

## Projects

### 01. Image Resizing

* Reads an image
* Resizes the image to 500 pixels wide
* Saves the resized image

### 02. Gaussian Blur

* Reads an image
* Converts the image to grayscale
* Applies Gaussian Blur for image smoothing
* Saves the blurred image

### 03. Webcam Stream

* Accesses the computer webcam
* Captures video frames in real time
* Displays the live video stream
* Press `q` to exit the webcam stream

## Technologies Used

* Python
* OpenCV
* imutils

## Installation

```bash
pip install opencv-python imutils
```
